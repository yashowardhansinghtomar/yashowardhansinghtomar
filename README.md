## Work I Am Proud Of

### Public Build: Groq Chat Bot

[Groq-chat-bot](https://github.com/yashowardhansinghtomar/Groq-chat-bot) is a lightweight Gradio app for testing Groq chat completions with separate system and user prompts.

What it shows:

- Simple LLM app structure using Python, Gradio, and Groq
- Prompt-control workflow with separate system and user inputs
- Fast prototype execution for testing assistant behavior

### RLHF and LLM Evaluation

Worked on frontier-model training workflows through Turing-sourced projects, contributing prompt design, side-by-side evaluation, and ground-truth corrections for Python and Data Science tasks.

What I handled:

- Designed single-turn and multi-turn prompts to expose reasoning, instruction-following, and coding failure modes
- Compared model outputs using structured rubrics across correctness, clarity, explainability, and instruction adherence
- Submitted corrections and preference judgments used to improve model behavior

### Voice AI Integration

Integrated text-to-speech and speech-to-text models into PreCall AI, a production AI-powered calling product.

What I handled:

- Connected model APIs into a live calling workflow
- Worked across audio input, transcription, response generation, and speech output
- Focused on making the system usable beyond a prototype environment

### Autonomous RL Trading System

Built ODIN, a personal autonomous stock trading system using reinforcement learning for signal generation and self-healing infrastructure for operations.

What it includes:

- Multi-source financial data ingestion
- Tensor-based reinforcement learning decision engine
- Heuristic override layer for edge-case market conditions
- Slack alerts for health checks, monitoring, and trade visibility
